**Requirements:** Node.js 18+ · Git

```bash
# Clone & Install
git clone https://github.com/LiveMedia48/Live-Media.git
cd Live-Media
npm install

# Start the bot
node bot.js
```

**Keep running 24/7 with PM2:**
```bash
npm install -g pm2
pm2 start bot.js --name live-media
pm2 save && pm2 startup
```

## ⚙️ Configuration

> Edit the `config.js` file to set up your bot.

| Variable | Default | Description |
|----------|:-------:|-------------|
| `BOT_NAME` | `Live-Media` | Bot display name |
| `PREFIX` | `.` | Command prefix (`.`, `,`, `!`, `/`) |
| `MODE` | `public` | `public` · `private` · `group` |
